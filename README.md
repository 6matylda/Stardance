# Stardance
Hey! This is my first Hack Club project: an airliner modeled in Onshape.
This model has 2 engines and features wings with a NACA 4412 airfoil and a NACA 0012 vertical stabilizer, whereas the horizontal stabilizers are custom.
I may optimize the model in the future for being an RC model.
Anyways, feel free to download the model and modify it however you want! :)
(As of aug/27/26 the model is still unfinished, currently in the stage of hollowing out the parts)
